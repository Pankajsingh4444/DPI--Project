# DPI - Deep Packet Inspection

## Goal

Build an MVP cybersecurity web application that captures live network packets and displays them in a dashboard.

## Tech Stack

Frontend
- React
- Vite
- TypeScript
- Tailwind CSS
- Axios
- Recharts

Backend
- Flask
- SQLAlchemy
- Flask-JWT-Extended
- Flask-CORS

Packet Capture
- Scapy

Database
- SQLite

Authentication
- JWT

## MVP Features

- Login
- Register
- Dashboard
- Live packet capture
- Packet table
- Packet details
- Protocol filter
- Port Scan Detection
- Ping Flood Detection
- Suspicious Port Detection
- CSV Export

## Coding Rules

- Modular code
- Functional React components
- No duplicated code
- Never rewrite working code
- Keep components reusable
- Explain major changes
- Build one feature at a time
